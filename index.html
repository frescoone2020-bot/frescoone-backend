Finance Analyzer

A local Python pipeline that turns raw e-commerce exports into a Net Profit dashboard, restock plan, and a searchable product-costing database — all running on your own machine.

What it does

Net Profit Dashboard

Reconciles D2C orders, dropship/reseller invoices, bank statements, and payroll into one accrual P&L, with a separate pure-cash view.

ISKU Pricing Database

A local product-costing database (import price, tax, invisible costing fees, currency, RSP/DSP) with a full add/search/edit/bulk-edit UI — no spreadsheet needed.

Restock Planning

Turns recent sales velocity and current stock into a funded purchase plan, with brand-mix and sellout-driven strategy views.

Why local-first

Every input file (orders, bank statements, payslips, supplier costs) and every output (the dashboard, the report) stays on your machine. Nothing is uploaded anywhere by default. The dashboard is a single static HTML file you open in a browser, served locally — there's no server component and no external database.

Getting started

  1. Install dependencies: pip install pandas openpyxl pdfplumber
  2. Drop your data exports into the project folder (see the scripts' docstrings for the expected file patterns).
  3. Run python finance_analyzer.py — this writes Executive_Financial_Report.md and dashboard.html.
  4. Open dashboard.html in a browser (or run Start_Dashboard.bat on Windows, which serves it on localhost and opens it for you).
pip install pandas openpyxl pdfplumber
python finance_analyzer.py

Project layout

  • finance_analyzer.py — the main pipeline: loads all data sources, computes Net Profit, generates the report and dashboard (including the ISKU Manager tab).
  • migrate_isku_database.py — one-time/re-runnable migration that builds the local product-costing database from a spreadsheet export.
  • restock_planner.py, restock_pipeline.py, restock_strategy.py — restock quantity/budget planning, layered on top of the same cost/sales data.
  • Start_Dashboard.bat — convenience launcher for the generated dashboard on Windows.
This repository intentionally contains code only. Real business data — generated reports, the dashboard output, the product-costing database, and every raw input file — is excluded via .gitignore and never committed. See README.md for the full list.
